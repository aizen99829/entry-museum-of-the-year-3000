# Museum of the Year 3000

An entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun: a single museum label, written as if it hung beside an ordinary object in a museum in the year 3000.

## The label

> The Group Chat, c. 2026. One question was asked. Nobody answered it. Four hundred messages later, dinner is still undecided.

The exhibit is the group chat — the most crowded room of the 2020s. Dozens of adults, one simple question, and a scroll of replies that answers everything except the question itself. The label treats that noise with total curatorial calm, as if future historians had already given up too. The joke is the gap between the formal museum voice and a failure everyone recognises from their own phone.

## How it works

`main.py` validates the label — exactly one line, at most 200 characters — prints it, and writes it to `/output/entry.txt`, which is what the make.fun harness grades.

```sh
python3 main.py
```
